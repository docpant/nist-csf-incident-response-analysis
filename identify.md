# Identify

## Type of Attack

The incident involved a denial of service (DoS) attack using ICMP flooding.

## Systems Impacted

- Internal network services
- Firewall infrastructure
- Network resource availability
- Employee access to network systems

## Vulnerabilities Identified

- Unconfigured firewall rules
- Insufficient traffic filtering
- Limited monitoring of abnormal ICMP activity

## Security Risks

The vulnerabilities increased the risk of:
- service disruption
- unauthorized traffic access
- network resource exhaustion
